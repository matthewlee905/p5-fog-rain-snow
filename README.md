# 霧、雨和雪是怎樣形成的？

香港小五科學課件，用來逐步觀察課本第 72–73 頁「霧、雨和雪是怎樣形成的？」的過程。

## 怎樣開啟

用 iPad Safari 打開本資料夾的 `index.html`。也可以把資料夾放到學校網絡，以 http 開啟。無需登入，無需網絡。

建議用 Safari 或 Chrome 開啟；用檔案（file://）或網頁（http://）都可以。

## 怎樣用

1. 按「下一步」，先看海水受熱、蒸發成水蒸氣。
2. 分開探索「近地面」和「高空」兩條路徑。高空成雲後，再分別看「小水滴積聚變重」和「小水滴上升成冰晶」。冰晶路徑可以選擇空氣溫度和接近地面的溫度。
3. 兩條主要路徑都探索完後，可打開「全部過程」。
4. 「短練習」有支援、基本、挑戰三層，答完會即時看到回饋，可以重試。

更完整的說明見頁面最下方的「老師說明」（預設收起）。
